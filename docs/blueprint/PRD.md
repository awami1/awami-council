# PRD — وثيقة متطلبات المنتج
# مجلس عائلة العوامي (Awami Council)

---

## 1. نظرة عامة على المنتج

### 1.1 وصف المنتج
منصة ويب متكاملة لإدارة مجلس عائلة العوامي — مجلس عائلي حقيقي تأسس عام 1992م (1413هـ). تخدم المنصة كمركز رقمي لإدارة شؤون العائلة بما يشمل: إدارة الأعضاء، المالية، الفعاليات، اللجان، شجرة العائلة، الأخبار، المعرض المرئي، والتفاعل المجتمعي.

### 1.2 المشكلة التي يحلها
- صعوبة تتبع بيانات أعضاء العائلة يدوياً
- عدم وجود نظام مالي شفاف لإدارة اشتراكات ومصروفات المجلس
- تشتت التواصل بين أفراد العائلة
- صعوبة حفظ وعرض شجرة العائلة بشكل تفاعلي
- غياب أرشيف رقمي للفعاليات والأخبار والصور

### 1.3 الفئة المستهدفة

| الفئة | الوصف | الصلاحيات |
|-------|-------|-----------|
| **الزائر العام** | أي شخص يزور الموقع | تصفح الصفحات العامة، إرسال رسائل تواصل، عرض شجرة العائلة والأخبار والفعاليات |
| **المشرف (Admin)** | مسؤول المجلس | جميع صلاحيات الإدارة: أعضاء، مالية، فعاليات، لجان، أخبار، إعدادات |

### 1.4 اللغة والاتجاه
- **اللغة الأساسية**: العربية
- **اتجاه الواجهة**: RTL (من اليمين لليسار)
- **جميع النصوص**: عربية (رسائل خطأ، عناوين، تسميات)
- **المصطلحات التقنية**: إنجليزية في الكود فقط

## 2. الميزات الكاملة

### 2.1 إدارة الأعضاء (Members Management)

**الهدف**: تتبع وإدارة بيانات جميع أعضاء المجلس

**المستخدم**: المشرف

**السيناريوهات الأساسية**:
- عرض قائمة الأعضاء مع بحث وفلترة حسب الحالة
- إضافة عضو جديد (اسم، عائلة، هاتف، رقم هوية، تاريخ انضمام، فرع)
- تعديل بيانات عضو قائم
- حذف عضو
- تعيين عضو في لجنة أو إزالته
- استيراد أعضاء بالجملة من ملف Excel

**المدخلات**:
- الاسم (مطلوب)، اسم العائلة، رقم الهاتف، رقم الهوية (فريد)
- تاريخ الانضمام، الحالة (نشط/معفي/غير نشط)، ملاحظات، الفرع

**المخرجات**:
- قائمة الأعضاء مع Pagination
- بيانات العضو الكاملة
- إحصائيات (عدد النشطين، المعفيين، غير النشطين)

**الحالات الاستثنائية**:
- رقم هوية مكرر (خطأ 409)
- حقول مطلوبة فارغة (خطأ 422)
- حذف عضو مرتبط بمدفوعات (يتم حذف المدفوعات تلقائياً عبر CASCADE)

---

### 2.2 النظام المالي (Financial System)

#### 2.2.1 الفترات المالية (Periods)

**الهدف**: تعريف فترات جمع الاشتراكات

**المدخلات**: اسم الفترة، مبلغ الاشتراك، تاريخ البداية والنهاية

**السيناريوهات**:
- إنشاء فترة مالية جديدة (مثال: "اشتراك 2024 — 200 ريال")
- عرض جميع الفترات
- حذف فترة (يحذف المدفوعات المرتبطة عبر CASCADE)

#### 2.2.2 المدفوعات (Payments)

**الهدف**: تتبع دفع اشتراكات الأعضاء

**المدخلات**: معرف العضو، معرف الفترة، المبلغ المدفوع، المبلغ المطلوب، تاريخ الدفع، طريقة الدفع، الحالة (مدفوع/لم يدفع/معفي)

**السيناريوهات**:
- عرض مدفوعات فترة معينة مع إحصائيات (مدفوع/معلق/معفي)
- تسجيل دفعة جديدة أو تحديث قائمة (Upsert)
- فلترة حسب العضو أو الفترة أو الحالة
- عند تسجيل دفعة "مدفوع" يتم إنشاء معاملة إيراد تلقائياً

**الحالات الاستثنائية**:
- محاولة إنشاء دفعة مكررة لنفس العضو والفترة (خطأ 409 أو Upsert)
- مبلغ غير رقمي (خطأ 422)

#### 2.2.3 المعاملات المالية (Transactions)

**الهدف**: سجل شامل للإيرادات والمصروفات

**المدخلات**: النوع (إيراد/مصروف)، المبلغ، الفئة، الوصف، التاريخ، اللجنة (اختياري)

**السيناريوهات**:
- عرض جميع المعاملات مع فلترة (نوع، تاريخ، لجنة)
- إضافة معاملة جديدة
- إضافة معاملات بالجملة (Bulk Insert) مع كشف التكرار
- عرض ملخص (إجمالي الإيرادات، المصروفات، صافي الربح)
- حذف معاملة

---

### 2.3 إدارة اللجان (Committees)

**الهدف**: تنظيم اللجان المختلفة وأعضائها

**المستخدم**: المشرف

**السيناريوهات**:
- عرض جميع اللجان مع عدد الأعضاء والفعاليات
- إنشاء لجنة جديدة (اسم، أيقونة، لون التدرج، وصف، استشارية/عادية)
- تعديل بيانات لجنة
- حذف لجنة (يحذف ارتباطات الأعضاء)
- إضافة/إزالة أعضاء من لجنة

**البيانات الافتراضية**: 11 لجنة مُعرفة مسبقاً (العمرة الرجبية، غداء العيدين، المسابقة الرمضانية، الرحلات، ليلة القدر، تنظيف المساجد، مسابقة العيد، الاستثمار، الاستشارية، الإعلامية، العقيقة الجماعية)

---

### 2.4 إدارة الفعاليات (Events)

**الهدف**: تتبع فعاليات ومناسبات المجلس

**المستخدم**: المشرف (إدارة) / الزائر (عرض)

**السيناريوهات**:
- عرض الفعاليات مع فلترة حسب الحالة (قادم/جاري/مكتمل/ملغي)
- إنشاء فعالية (اسم، لجنة، حالة، تاريخ، ميزانية، عدد المشاركين، المسؤول، أيقونة، صور)
- تعديل/حذف فعالية
- عرض الفعاليات القادمة في الصفحة الرئيسية (3 فعاليات)

**المدخلات**: الاسم (مطلوب)، التاريخ، اللجنة، الحالة، الميزانية، عدد المشاركين، المسؤول، ملاحظات، أيقونة emoji، قائمة صور (URLs)

---

### 2.5 شجرة العائلة (Family Tree)

**الهدف**: عرض تفاعلي لشجرة العائلة الهرمية

**المستخدم**: الجميع (عرض) / المشرف (إدارة)

**السيناريوهات**:
- عرض الشجرة بشكل هرمي باستخدام D3.js
- بحث بالاسم مع نتائج فورية
- توسيع/طي الفروع
- عرض تفاصيل الشخص عند التمرير (الاسم، الجنس، الزوج/ة، الأبناء، الأب)
- تمييز بالألوان: ذكر (أخضر)، أنثى (بنفسجي)، متوفي (رمادي)
- إضافة/تعديل/حذف أفراد (المشرف فقط)
- عند حذف شخص يتم نقل أبنائه لجده

**المدخلات**: الاسم (مطلوب)، الأب (parent_id)، الجنس (ذكر/أنثى)، حالة الحياة، اسم الزوج/ة، ترتيب العرض

---

### 2.6 فروع العائلة (Family Branches)

**الهدف**: تنظيم العائلة إلى فروع

**السيناريوهات**:
- عرض جميع الفروع
- إنشاء فرع (اسم، رئيس الفرع، عدد الأعضاء، لون، ملاحظات، قائمة أعضاء)
- تعديل/حذف فرع

---

### 2.7 الأخبار (News)

**الهدف**: نشر أخبار ومقالات المجلس

**المستخدم**: الجميع (قراءة المنشور) / المشرف (الكتابة والإدارة)

**السيناريوهات**:
- عرض الأخبار المنشورة مع فلترة حسب الفئة (7 فئات: عام، فعاليات، إعلانات، اجتماعات، مالية، اجتماعية)
- كتابة خبر جديد (عنوان، محتوى، مقتطف، صورة، فئة، كاتب، حالة)
- تعديل/حذف خبر
- بحث في الأخبار
- الزوار يرون المنشور فقط، المشرفون يرون الكل (بما فيها المسودات)
- عرض آخر 3 أخبار في الصفحة الرئيسية

**الفئات**: عام، فعاليات، إعلانات، اجتماعات، مالية، اجتماعية

**الحالات**: published (منشور)، draft (مسودة)

---

### 2.8 المعرض المرئي (Media Gallery)

**الهدف**: عرض صور وفيديوهات المجلس

**المستخدم**: الجميع (عرض) / المشرف (إدارة)

**السيناريوهات**:
- عرض المعرض مع فلترة (الكل/صور/فيديوهات/يوتيوب)
- إضافة عنصر (عنوان، URL، نوع، تاريخ، وسوم)
- تعديل/حذف عنصر
- عارض Lightbox بملء الشاشة مع تنقل سابق/تالي
- دعم: صور، فيديوهات محلية، فيديوهات يوتيوب

**ملاحظة تقنية**: المعرض يُخزن داخل جدول website_settings (حقل media) كـ JSON وليس في جدول منفصل.

---

### 2.9 التصويت (Polls)

**الهدف**: إجراء استطلاعات رأي لأعضاء المجلس

**المستخدم**: المشرف (إنشاء وإدارة) / الأعضاء (التصويت)

**السيناريوهات**:
- إنشاء استطلاع (عنوان، خيارات 2+، لجنة، تاريخ الانتهاء)
- التصويت (صوت واحد لكل مستخدم لكل استطلاع — يمكن تغيير الصوت)
- عرض النتائج الحية
- إغلاق الاستطلاع (منع التصويت الجديد)
- حذف الاستطلاع

**القيود**:
- 2 خيارات على الأقل
- صوت واحد فقط لكل مستخدم (UNIQUE constraint)
- لا يمكن التصويت على استطلاع مغلق

---

### 2.10 رسائل التواصل (Contact Messages)

**الهدف**: استقبال رسائل الزوار

**المستخدم**: الزائر (إرسال) / المشرف (قراءة وإدارة)

**السيناريوهات**:
- إرسال رسالة (اسم، هاتف، موضوع، رسالة) — بدون تسجيل دخول
- حماية من البوتات عبر Honeypot field
- Rate Limiting: 5 رسائل/ساعة لكل IP
- عرض الرسائل الواردة (المشرف)
- تحديد كمقروءة
- حذف رسالة
- عدد الرسائل غير المقروءة

---

### 2.11 التقارير الذكية (Smart Reports — AI-Powered)

**الهدف**: تحليل ذكي للبيانات المالية من ملفات Excel

**المستخدم**: المشرف

**السيناريوهات** (Stepper UI من 5 خطوات):
1. **رفع ملف Excel** (XLSX) — Drag & Drop أو اختيار
2. **معاينة وكشف الأعمدة تلقائياً** (التاريخ، المبلغ، الوصف، النوع)
3. **تنظيف البيانات** (إزالة صفوف المجاميع، تحويل أرقام عربية)
4. **تصنيف ذكي** (18+ كلمة مفتاحية للتصنيف التلقائي بمستوى ثقة)
5. **مراجعة وتحرير** (تعديل مباشر في الجدول، إجراءات بالجملة)

**المخرجات**:
- ملخص تحليلي (إجمالي إيرادات/مصروفات/صافي ربح)
- تصنيف كل معاملة حسب الفئة
- تصدير CSV
- حفظ التقرير في قاعدة البيانات
- مزامنة المعاملات مع سجل الميزانية

### 2.12 الاجتماع القادم (Next Meeting)

**الهدف**: عرض العد التنازلي للاجتماع القادم

**المستخدم**: الجميع (عرض) / المشرف (إدارة)

**السيناريوهات**:
- عرض عداد تنازلي (أيام، ساعات، دقائق) في الصفحة الرئيسية وصفحة المجلس
- عرض التاريخ بالتقويمين الهجري والميلادي
- إخفاء/إظهار العداد
- تحديث موعد الاجتماع
- حذف موعد الاجتماع

### 2.13 تهنئة العيد (Eid Greeting Card)

**الهدف**: إنشاء بطاقة تهنئة عيد مخصصة

**المستخدم**: الجميع

**السيناريوهات**:
- كتابة الاسم
- اختيار حجم الخط (40-120px) ونوعه (عادي/سميك)
- معاينة حية على Canvas
- تحميل البطاقة كصورة PNG
- مشاركة عبر WhatsApp أو Web Share API

### 2.14 إعدادات الموقع (Website Settings)

**الهدف**: تخصيص محتوى الموقع العام بدون تعديل الكود

**المستخدم**: المشرف

**الأقسام القابلة للتعديل**:
- **الرأس (Header)**: العنوان والعنوان الفرعي
- **البطل (Hero)**: نص الترحيب والوصف
- **الإحصائيات**: سنوات التأسيس، عدد اللجان، عدد الأعضاء
- **الشعار (Logo)**: رفع شعار مخصص أو الافتراضي
- **عن المجلس (About)**: الرسالة والرؤية
- **المناصب (Council Positions)**: إضافة/تعديل/حذف مناصب المجلس
- **القيم (Values)**: إضافة/تعديل/حذف قيم المجلس
- **التواصل (Contact)**: رقم WhatsApp

- تسجيل تذكير فردي أو بالجملة

## 3. رحلات المستخدم (User Flows)

### 3.1 رحلة الزائر العام
```
الصفحة الرئيسية → تصفح الأقسام (المجلس/الشجرة/الأخبار/الفعاليات/المعرض)
                 → عرض العد التنازلي للاجتماع
                 → إرسال رسالة تواصل
                 → إنشاء بطاقة تهنئة عيد
                 → عرض شجرة العائلة التفاعلية
                 → قراءة الأخبار المنشورة
                 → تصفح المعرض المرئي
```

### 3.2 رحلة المشرف
```
/admin → تسجيل الدخول (username + password)
      → لوحة التحكم (إحصائيات، نشاط أخير)
      → إدارة الأعضاء (CRUD + استيراد)
      → إدارة المالية (فترات → مدفوعات → معاملات)
      → إدارة اللجان (CRUD + تعيين أعضاء)
      → إدارة الفعاليات (CRUD)
      → إدارة الأخبار (CRUD)
      → إدارة شجرة العائلة
      → التصويت (إنشاء/إغلاق/حذف)
      → التقارير الذكية (رفع Excel → تحليل → حفظ)
      → الرسائل الواردة (قراءة/حذف)
      → إعدادات الموقع
      → سجل التدقيق
      → التصدير
      → تسجيل الخروج
```

### 3.3 رحلة تسجيل الدخول
```
1. المستخدم يفتح /admin
2. يُدخل اسم المستخدم وكلمة المرور
3. الخادم يتحقق من بيانات الاعتماد (bcrypt hash أو نص عادي)
4. Rate Limiting: 5 محاولات / 15 دقيقة
5. عند النجاح: إنشاء جلسة + CSRF token + تجديد Session ID
6. عند الفشل: رسالة خطأ + تأخير 300ms + تسجيل المحاولة
7. تسجيل الخروج: تدمير الجلسة + مسح الكوكيز
```

### 3.4 رحلة التصفح العام (SPA-like)
```
1. المستخدم يفتح أي صفحة عامة
2. ajax-nav.js يعترض النقر على الروابط الداخلية
3. يُرسل طلب XHR مع ?_ajax=1 (يعيد المحتوى بدون Layout)
4. يُحدّث #page-content + History API + عنوان الصفحة
5. يُحمّل Scripts خاصة بالصفحة ديناميكياً
6. يُعيد تهيئة الـ Animations
```

## 4. متطلبات غير وظيفية

### 4.1 الأمان
- مصادقة Session-based مع كوكيز SameSite=Strict, HttpOnly
- حماية CSRF لجميع عمليات الكتابة
- Rate Limiting على تسجيل الدخول والرسائل
- Honeypot لنماذج الاتصال
- حد أقصى لحجم الطلب: 64KB
- تنظيف المدخلات (htmlspecialchars)
- Prepared Statements لجميع استعلامات SQL
- Security Headers: X-Content-Type-Options, X-Frame-Options, HSTS

### 4.2 الأداء
- لا يوجد Build Step — ملفات مباشرة
- Cache Busting عبر filemtime
- تحميل كسول للصور (loading="lazy")
- تحميل Scripts عند الطلب (per-page)

### 4.3 التوافق
- تصميم متجاوب (Mobile-first)
- PWA مع Service Worker (offline fallback)
- دعم Dark Mode
- دعم شاشات اللمس
- RTL بالكامل

### 4.4 إمكانية الوصول
- Skip Link
- ARIA labels
- Keyboard Navigation
- Focus Trapping في Modals و Lightbox
- ألوان بتباين كافٍ (WCAG AA)
- prefers-reduced-motion
